# 06 — User Profile & GitHub Graph

**What to build:** A profile view that displays user details and dynamically renders their GitHub contribution graph as an image. This page is accessed by clicking on a user's avatar anywhere in the app (e.g., from a chat or community post).

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [x] Build a Profile screen that accepts a user ID and fetches their data.
- [x] Display standard user details (Name, Bio, etc.).
- [x] Use an open-source image generation API (like `ghchart.rshah.org`) to fetch and display the user's GitHub contribution graph as they scroll down.
- [x] Ensure avatars in the app are clickable and route to this Profile screen.
