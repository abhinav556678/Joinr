# 01 — Global Typography Update (Inter Font)

**What to build:** The entire application should render text using the "Inter" font by default, ensuring a consistent typographical style across all screens. The font must be loaded properly at the app's entry point before rendering the UI.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] "Inter" font family is installed or loaded via Expo Google Fonts / local assets.
- [ ] Global text styles or the root navigation layout apply the font as the default for all Text components.
- [ ] Verification across both Android and iOS that the font applies successfully without layout breakage.
